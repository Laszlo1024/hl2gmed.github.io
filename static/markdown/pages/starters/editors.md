As noted in the welcome tutorial Lua is plain text, so you can edit it in text editor, but you'll probably find you want something a bit better. The editors below are listed because they are the most popular editors in the Null's Box community.

# ACode (Recommended)

[ACode](https://acode.app), open-source Android IDE that combines a professional code editor, a full Alpine Linux terminal, and native support for AI coding agents — Claude Code, OpenAI Codex, and OpenCode. It has 3.6M+ downloads and 5,458+ GitHub stars. Licensed under MIT.
- Recommended by [Dim1xs](https://github.com/Dim1xs)

# Visual Studio Code Browser
[Visual Studio Code Browser](https://vscode.dev), commonly referred to as VS Code, VSCode, or VSC, is a lightweight, free, open-source code editor created by Microsoft. It offers a range of powerful IDE features such as language server protocol support, a massive extension marketplace, and built-in support for Git, FTP & SSH. It supports inline-documentation (an immeasurably valuable feature when attempting to navigate the often incomprehensible world of Source modding), refactoring, reference jumping, and code completion. VS Code is currently the recommended development environment for Garry's Mod script development, due to VS Code's prominent role in the development community, as well as the community's efforts to develop Lua/GLua extensions.
- Recommended by [Laszlo](https://github.com/Laszlo1024)
